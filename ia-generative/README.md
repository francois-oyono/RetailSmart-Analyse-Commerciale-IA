# IA générative — RetailSmart

## Objectif

Expérimenter la création d'un tableau de bord commercial par une IA générative, à partir des fichiers CSV du projet RetailSmart.

## Démarche prévue

1. Fournir à l'IA les données commerciales.
2. Définir les indicateurs métier à analyser.
3. Demander la création d'un tableau de bord indépendant.
4. Comparer les KPI obtenus avec le rapport Power BI de référence.
5. Identifier les écarts, les limites et les corrections nécessaires.

## Indicateurs à comparer

- Chiffre d'affaires net
- Nombre de commandes
- Panier moyen
- Quantités vendues
- Performances des produits et catégories
- Répartition géographique des ventes
- Marge simulée

## Référence Power BI

Le rapport Power BI utilisé pour la comparaison est une correction pédagogique fournie par l'organisme de formation.

## Statut

Expérimentation à réaliser.

## Compétences visées

Prompt engineering, analyse commerciale, validation des KPI et contrôle critique des résultats produits par l'IA.
